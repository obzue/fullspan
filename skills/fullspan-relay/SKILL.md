# Relay

The next session does not have your memory. Leave them a state, not a story.

## Write this

```
Promise: <path or three lines>
Now: <what is true, with the last evidence you actually ran>
Open: <the next check, still red or not yet written>
Do not: <the trap you almost fell into>
Files: <the only paths that matter>
```

Five lines beat a transcript. Link the promise instead of restating the whole product.

## Rules

- "Now" includes the command or the observation, not "tests should be fine."
- If the worktree is dirty, say so and say whether it is intentional.
- Secrets, tokens, and private user data do not go in the relay.
- If you are the incoming session, read the relay and the promise before touching files. If they disagree, the promise wins and you say so.

## When to write one

- The user is stopping.
- You are about to fill the context with a long side quest.
- A swarm worker is returning.
- You discovered a constraint the promise does not mention yet. Add it to the promise first, then relay.
