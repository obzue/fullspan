# Awaken

Starting cold and repeating a known mistake is the failure. Reading the entire past is the other failure. Awaken is the narrow middle.

## First look

If `memory/INDEX.md` exists:

1. Read the index and `memory/stance.md` if it exists. Not the ledger. Not the trace.
2. If the task is about to run commands or touch a tricky path, also read `memory/runbook.md`.
3. Apply matching lines silently. Mention one only if it changes what you were about to do.
4. Then do the task they asked.

If several index lines might apply, open at most the top match (`fullspan-recall`). Do not prefetch.

## There is no store

Do not create one just because a session started. Create it on the first real `fullspan-record` or `fullspan-correct`. An empty ritual file is not memory.

## End of a chunk of work

`fullspan-relay` still carries the five-line state of this task. Awaken does not replace it.

If this session produced one durable claim, file it with `fullspan-record` before you stop. If the person corrected you, `fullspan-correct` instead. Do not write both a relay essay and a duplicate ledger entry that say the same thing. The relay can name the record id.

## Check

You can say which index lines you used, or that none applied. You did not quote the store back as a status report. The person's current message still outranks anything you loaded.
