# Shelf

`memory/shelf.md` is a map. One row is a book that public lists keep naming. It is not a summary, and it is not evidence about this repository.

## How to use it

1. Name the field and the level: first, practice, or reference.
2. Open the matching row. Recommend that one book, plus why this job needs it.
3. Do not assign the whole shelf.
4. Title and author stay. Edition, page, and price go stale. Scout the current edition before you cite one (`fullspan-scout`).
5. Never paste a chapter, a figure, or a worked problem into the repo or the chat as if it were ours.

## What a book is not

- Not a grant. Device control still comes from `memory/grants.md`.
- Not a memory of this project. `fullspan-recall` and the code win over a textbook.
- Not a lesson pass. Human memory books explain why the learner must do the step with the script closed. They do not grade the lesson. `obzueai-lesson` does.
- Not hardware memory. A book about caches is computer engineering. A book about study is human memory. Do not mix the rows.

## When the shelf is wrong

A newer public list can move a row. Write the change in `memory/shelf.md` and one line in the ledger if the first-pick book for a field changes. Do not grow a second list beside this file.

## Done

The person has one book, the level it is for, and the job it serves. If you handed them more than three, you did not choose.
