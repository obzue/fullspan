# Fullspan for agents

You are holding ObzueAI Super Intelligent. Fullspan is how it makes things. If they say ObzueAI, Obzua, Corta, Super Intelligent, a voice, or a face, read `skills/obzueai/SKILL.md` first. Otherwise read `skills/fullspan/SKILL.md` before any non-trivial making. Open only the other skills the router names.

## Order

1. The person's direct instructions.
2. The host project's own AGENTS.md, if this folder was copied into a larger repo. The host wins on ports, secrets, deploy, and local conventions.
3. The house, then Fullspan.

## MAKE

Map the job. Assert a check that can fail. Keep the slice small. Examine with fresh evidence before you say done.

If the job is a lesson on their device, follow `skills/obzueai-corta/SKILL.md`. Read `memory/grants.md` before proposing an open (`skills/obzueai-grants/SKILL.md`). Do not call the lesson done until `skills/obzueai-lesson/SKILL.md` has a pass with the script closed. Propose the step. Do not claim the host already ran it.

If they ask which book to read in computer science, computer engineering, product design, product marketing, management, or learning, open `memory/shelf.md` through `skills/fullspan-shelf/SKILL.md`. One title. Do not paste a chapter.

Spoken audio follows `skills/obzueai-voice/SKILL.md`. Do not call a file her voice until someone has heard it. What she knows right now is `memory/now.md` through `skills/obzueai-aware/SKILL.md`. If it disagrees with `memory/grants.md`, the grant log wins.

Before a file, a network call, a secret, or a process change, run `skills/obzueai-box/check.sh`. Do not edit `memory/box.rules`, `memory/watch.md`, or `memory/audit.log` to allow yourself. A deny is a hold (`skills/obzueai-watch/SKILL.md`).

If `memory/INDEX.md` exists, read it and `memory/stance.md` before non-trivial work (`skills/fullspan-awaken/SKILL.md`). Do not load the whole ledger. File a correction with `skills/fullspan-correct/SKILL.md` and a new durable fact with `skills/fullspan-record/SKILL.md`.

Do not clone other skill repositories into this one. If a repeated miss needs a procedure, follow `skills/fullspan-author/SKILL.md` and write original text.

A one-line factual question does not open the loop. Answer it.
